The swatch picker lets a buyer choose up to 3 of the 22 Cores Cergam and see the print on a bottle, which turns Cergam's main technical fact into the main interaction.

- 22 round swatches (`cergam-c*` tokens) in a group: 11 by 2 on desktop, 6 columns on tablet, 4 on phones. Circle about 40px with a 44px target.
- Every swatch shows its code in mono (C12). Colour is never the only identifier.
- Selected state: 3px `primary` ring plus a check mark. Maximum 3 colours (the current site quotes black or 1, 2 or 3 colours); a fourth pick shows a short message and changes nothing.
- The bottle preview sits on a neutral light panel, even in the dark theme, and the print changes colour in `dur-swatch` (240ms). Note below: "Cor aproximada no ecrã. Peça uma prova física."
- Light swatches (C4, C5, C6) keep a 1px outline so they stay visible.
- The picked colours travel into the quote form ("Cores: C12, C5").
- The consumer provides the swatch data from one file (code, names in four languages, hex on clear glass and on white glass, sampled date, status). Values here are screen samples, not a print standard.
