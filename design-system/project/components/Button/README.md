Buttons start one action each, and the quote button is the one that matters most on this site.

- **Primary:** fill `primary`, label `on-primary`, 48px high, `radius-control`. One per page region. The label is a verb: "Pedir orçamento".
- **Secondary:** 1.5px `primary` outline, transparent. Hover fills with `primary`. Sits beside a primary.
- **Link-arrow:** `link` text with a thin arrow that grows 6px on hover. For "Ver exemplos". Never the only action on a page.
- Focus is a 3px `accent` ring with a 2px offset. Targets are 44px minimum.
- The consumer provides the click handler and the label in the page language.
