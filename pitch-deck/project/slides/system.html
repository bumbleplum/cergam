O sistema de design chama-se Carta Cergam: a página funciona como uma tabela de cores de gráfica. O interface é neutro para que as 22 Cores Cergam sejam a única cor forte. Os valores aqui são medidos no ecrã a partir da imagem da tabela do site atual, não são um padrão de impressão. Antes de lançar é preciso medir as cores reais a partir de peças cozidas.
